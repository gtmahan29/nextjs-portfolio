# Cloud texture

`cloud-puff.png` is the default cloud texture used by the installed
`@react-three/drei` Cloud component, from pmndrs/drei-assets:

https://github.com/pmndrs/drei-assets/blob/9225a9f1fbd449d9411125c2f419b843d0308c9f/cloud.png

The arrangement and animation in `components/journey/hero-clouds.ts` are authored
for this project. The SkyClinics site was used as a visual and technical reference;
its models, photographs, and site texture files were not copied.

The Blender cloud authoring experiments remain in `hero-clouds.blend`.
